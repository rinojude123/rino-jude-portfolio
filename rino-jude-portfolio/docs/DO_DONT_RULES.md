# DO_DONT_RULES.md

## DO

- keep the information architecture conventional
- use the warm off-white paper background
- use dark graphite/ink lines
- use Space Grotesk + DM Sans + IBM Plex Mono + Caveat exactly by role
- make sketch imperfections intentional and controlled
- use engineering marks sparingly
- use hand-drawn borders and subtle arrow/underline drawing
- keep the custom cursor simple
- use the hero reveal as the signature interaction
- use ink-draw-on-scroll for selected marks
- keep mobile layouts clean and simplified
- keep project data centralized
- keep animations purposeful
- respect reduced motion
- use real project information only
- make unavailable project details obvious rather than invented

## DON'T

- do not use giant gradients
- do not use glassmorphism
- do not use fake skill percentages
- do not use a giant WebGL cursor
- do not make a full-screen 3D lab environment
- do not add random equations/scribbles
- do not turn every section into a notebook page with excessive decoration
- do not add a "currently exploring" section
- do not add a certifications section
- do not add a soft-skills section
- do not create a Projects index page
- do not make Resume a separate page
- do not make Contact a separate page
- do not hide important content behind hover
- do not claim the Smart Stethoscope is AI integrated
- do not claim the iontophoresis prototype is clinically validated or medically safe
- do not invent project screenshots, GitHub links, metrics, or technology details
- do not introduce a new visual theme during implementation
