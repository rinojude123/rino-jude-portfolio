# SEO.md

## Base title

`Rino Jude — Biomedical Engineering Student`

## Meta description

Use a concise description based on the locked About statement. Example:

`Rino Jude is a Biomedical Engineering student exploring technology across healthcare, AI/ML, software, embedded systems, design, and automation.`

## Project pages

Use descriptive titles such as:

`30-Day Post-ICU Readmission Prediction — Rino Jude`

Avoid keyword stuffing.

## Open Graph

Create a restrained `og-image.png` using the portfolio visual language.

Recommended size: 1200×630.

## Structured content

Use semantic headings and descriptive links so search engines can understand project titles, technologies, experience, and contact information.

## Canonical URL

Configure via environment/build config so production domain can be changed without editing many files.

## Robots/sitemap

Provide:

- `public/robots.txt`
- generated/static `sitemap.xml`

Include Home and project detail URLs that actually exist.
