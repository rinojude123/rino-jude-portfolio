# SITEMAP.md

## Public routes

### `/`
Home page containing:

- Preloader
- Navbar
- Hero
- About
- Projects
- Skills
- Experience
- Contact
- Footer

### `/project/:slug`
Reusable project detail template.

Examples:

- `/project/post-icu-readmission-prediction`
- `/project/pneumonia-detection`
- `/project/automated-medical-report-generation`
- `/project/smart-stethoscope`
- `/project/3d-printed-medical-model`
- `/project/scara-robot`
- `/project/smart-walking-stick`
- `/project/iontophoresis-device`

### `*`
Not Found page.

## Navigation anchors

- `#home`
- `#work`
- `#about`
- `#skills`
- `#experience`
- `#contact`

Navbar labels may remain `WORK`, `ABOUT`, `SKILLS`, `EXPERIENCE`, `CONTACT`.

No separate Projects index route.
