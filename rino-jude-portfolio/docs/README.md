# Rino Jude Portfolio — Master Build Package

This package is the implementation handoff for the Rino Jude personal portfolio.

## Start here

1. Read `MASTER_SPEC.md`.
2. Read `AGENTS.md` before modifying or generating code.
3. Read the design, page, component, animation, interaction, content, project, experience, asset, and technical documents referenced by the master spec.
4. Build the portfolio in React + Vite according to the specifications.
5. Do not redesign the concept while implementing it. Resolve implementation details in favor of the rules in `DO_DONT_RULES.md`.
6. Run the `FINAL_BUILD_CHECKLIST.md` before deployment.

## Locked direction

Normal portfolio structure. Experimental visual language.

Visual language: warm off-white engineering/sketchbook aesthetic, dark ink lines, subtle graphite construction marks, hand-drawn borders, technical labels, sparse handwritten annotations, and restrained motion.

Signature interaction: Image B (monochrome Meta Quest sketch) is the default hero visual. A cursor-following reveal mask reveals Image A (full-color illustration) beneath/over the same aligned composition.

No extra visual systems should be introduced beyond the package.
